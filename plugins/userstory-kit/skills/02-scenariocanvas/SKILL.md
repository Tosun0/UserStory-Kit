# 02. 시나리오 캔버스

플러그인 루트는 이 디렉터리의 `../..`다. [공통 지침](../../AGENTS.md)과 [원본 가이드](../../references/guidev0929.md)를 읽고 적용한다. 동일 작업에서 읽은 자료는 이어 사용한다.

1. 현재 시캔 코드와 원본 이미지의 카드/세로형 구분, 순서, 비율·바탕색을 확인한다. [제작 태스크](../../tasks/build.md)의 사본·슬롯 조립 규칙을 적용한다.
2. 카드형은 [canvascard](../../assets/components/canvascard.html)의 HTML·CSS·JS를 사용한다. 기존 통일 크기·전환·우측 상단 회색 숫자 캡슐을 유지하고 DPR·screen.width로 크기를 분기하지 않는다. 세로형은 [공통 img](../../assets/components/image.html)의 HTML·CSS로 원본 비율과 자연 스크롤을 유지한다. 정적 한 장은 img 하나다.
3. 부품에는 시캔 본문만 둔다. 플레이북·데이터북·헤더·main/section 골격을 다시 넣지 않는다. 작성된 SVG 애니메이션이나 인터랙션은 평탄화하지 말고 원본 기능을 시캔 슬롯에 조립한다.
4. 리소스는 `assets/scenariocanvas`에 복사해 상대 경로를 맞춘다. CSS/JS는 통합 파일의 해당 블록 코드만 작업하고 다른 블록과 공유 img 코드를 보존한다. 원본 이미지를 일괄 이동하거나 임의로 손실 압축하지 않는다.
5. 이미지 중심·비율·배경색과 합성 글의 실제 가림을 확인한다. 카드 전환은 실제 scrollY를 읽기만 하며 자동 스냅·강제 이동을 넣지 않는다. 두 해상도에서 각 카드/전환 또는 세로형 시작·중간·끝을 [검수 기준](../../tasks/audit.md)으로 확인한다.

전체 페이지 조립기를 단일 시캔 수정에 실행하지 않는다. 검수만 요청받으면 읽기 전용이며 변경 내역·검증 결과·미실행 항목을 [00. 총괄](../00-userstory/SKILL.md)에 넘긴다. 시캔 확인만으로 전체 콘텐츠 합격을 선언하지 않는다.
