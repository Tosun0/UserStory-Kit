# UserStory 검수

이 스킬의 디렉터리에서 `../..`가 플러그인 루트다.

1. [에이전트 지침](../../AGENTS.md)을 모두 읽고 [원본 가이드](../../references/guidev0929.md)를 3회 끝까지 읽는다. 동일 제작 작업에서 이미 3회 읽었다면 그 기록을 이어 사용한다.
2. [검수 태스크](../../tasks/audit.md)를 수행한다. 원문 7장·9장의 어느 항목도 생략하지 않는다.
3. HTML 골격 비교에는 [기준 템플릿](../../assets/template/index.html)을 사용한다.

검수 요청은 기본적으로 읽기 전용이다. 수정까지 요청받았거나 제작 태스크의 후속 검수인 경우에만 실패 항목을 수정하고 다시 검증한다. 코드 검사, 브라우저 확인, 플랫폼 게시 결과를 구분하여 보고한다. 미실행 항목을 합격으로 처리하지 않는다.
