# 03_데이터북

플러그인 루트는 이 디렉터리의 `../..`다. [공통 지침](../../AGENTS.md)과 [원본 가이드](../../references/guidev0929.md)를 읽고 적용한다. 동일 작업에서 읽은 자료는 이어 사용한다.

1. 데이터북 사용 여부와 현재 코드·제공 파일을 확인한다. 데이터북을 쓰지 않는 경우와 쓰기로 했지만 파일이 누락된 경우를 구분한다. 누락 파일을 가짜 데이터북이나 임의 생성 콘텐츠로 채우지 않는다.
2. 데이터북이 없으면 기준 템플릿의 ✂ 시작·끝 표시를 포함한 section 전체를 삭제한다. 기존 사본에서 표시가 없다면 `id="data-book"` 블록을 정확히 확인한 뒤 제거한다. 데이터북 전용 코드·리소스도 참조를 확인해 정리하되 다른 블록의 공유 코드는 남긴다.
3. 데이터북이 있으면 [제작 태스크](../../tasks/build.md)에 따라 제공된 HTML·이미지·로컬 PDF의 기능과 내용을 데이터북 슬롯에 조립한다. 이미지형은 [공통 img](../../assets/components/image.html)를 사용한다. 외부 뷰어를 호출하거나 요구되지 않은 복잡한 뷰어를 새로 만들지 않는다.
4. 리소스는 `assets/databook`에 복사하고 상대 경로와 대소문자를 맞춘다. HTML은 데이터북 슬롯, CSS/JS는 통합 파일의 해당 블록 코드만 작업한다. 플레이북·시캔과 기존 공유 코드의 사용처를 보존한다.
5. 선택 블록의 유무·식별자·경로, 이전 블록에서의 자연 스크롤 접근과 실제 표시를 [검수 기준](../../tasks/audit.md)으로 확인한다. 검수만 요청받으면 읽기 전용이다.

단일 데이터북 작업으로 전체 페이지를 재생성하지 않는다. 반영 또는 삭제한 내용, 누락 파일과 검증 결과·미실행 항목을 [00_총괄](../00-userstory/SKILL.md)에 넘기며 전체 콘텐츠 합격을 대신 선언하지 않는다.
