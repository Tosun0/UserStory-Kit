# UserStory 제작

이 스킬의 디렉터리에서 `../..`가 플러그인 루트다. 현재 작업 디렉터리나 개발 PC의 고정 경로로 자료를 찾지 않는다.

1. [에이전트 지침](../../AGENTS.md)을 끝까지 읽는다.
2. [원본 제작 가이드](../../references/guidev0929.md)를 3회 끝까지 읽는다. 1회는 전체 규칙, 2회는 템플릿·식별자·스크롤·레이아웃, 3회는 요청 충돌과 7장·9장 검수를 점검한다. 파일명은 v0929, 원문 표제는 v0824이며 원문을 임의로 고치지 않는다.
3. [기준 템플릿](../../assets/template/index.html), 그 옆 `assets/style.css`와 `assets/app.js`를 모두 읽는다.
4. [제작 태스크](../../tasks/build.md)를 수행한다. 제작 완료 뒤 [검수 태스크](../../tasks/audit.md)를 필수 후속 단계로 수행한다.

제목·필수 작업물·출력 위치가 없거나 작업물의 블록 구분이 모호하면 필요한 사항만 질문한다. 원본 템플릿은 수정하지 않고 출력 사본에만 작업한다. 등록·구상 요청을 실제 콘텐츠 제작이나 원격 배포 요청으로 확대하지 않는다.
